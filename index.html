Entry Points
  • First-time app download and launch
  • Club website redirect to app
  • Referral or invitation link
  • Social media or marketing campaign
Key Rules
  • Browsing is permitted without an account
  • No bookings can be made without registration
  • All class and trainer details are visible in read-only mode
  • A valid email or phone number is required to register
  • Membership must be active before app access is granted
Alternative Paths

  • Register at the club reception in person
  • Call the club to set up membership before using the app

Entry Points
  • Book tab in bottom navigation
  • Timetable quick action on home dashboard
  • My Schedule — browsing empty time slots
  • Push notification for new or recommended classes
  • Deep link from email or club communication
  • Search from anywhere in the app
Key Rules
  • Free classes confirm immediately — no payment step
  • Paid classes require payment before confirmation is issued

  • Late cancellation may result in a charge or credit loss
  • Booking window opens a set number of days in advance per club policy

  • A member may book for additional guests subject to guest policy
Alternative Paths

  • Join the Alert Me waitlist if the class is full
  • Book an equivalent class at a different club location
  • Contact reception to make or modify a booking
  • Book via the club website (if available)

Entry Points
  • Courses section in app navigation
  • Home dashboard featured or promoted courses
  • Email or push notification about new course availability
  • Category browsing within class discovery
Key Rules
  • Courses are booked and paid for in full — no session-by-session booking
  • Individual sessions within a course cannot be booked separately
  • All sessions are reserved simultaneously at point of booking

  • Partial refunds for missed sessions are subject to club policy
  • Some courses may have prerequisites or age restrictions
Alternative Paths

  • Book individual drop-in classes if a course is unavailable
  • Contact reception to enquire about course waitlists
  • Book via the club website if available

Entry Points
  • Class detail page when the class is shown as fully booked
  • Class list view when a class displays a "full" status indicator
Key Rules
  • Alert Me is only available on fully booked classes
  • Notification is sent when a space becomes available — member must act quickly
  • Alert applies to a specific class instance (date and time), not all future occurrences
  • Only one alert per class instance per member
  • Alert is automatically cleared once the class date passes
  • If the notification is not acted on promptly, the space may be taken by another member
Alternative Paths
  • Book the same class on a different available date or time
  • Book a similar class in the same category
  • Check back manually for cancellations without setting an alert
  • Contact reception — they may be able to add to a managed waitlist

Entry Points
  • Class detail page for eligible recurring classes
  • Class list view where rolling booking is indicated as available
  • My Schedule — converting a one-off booking into a rolling one
Key Rules
  • Rolling bookings are only available on eligible recurring classes
  • All future sessions are automatically reserved once set up
  • An individual session can be cancelled without affecting the rest of the rolling schedule
  • Cancelling all sessions removes all future occurrences at once
  • Same 24-hour cancellation policy applies to each individual session
  • Changes to the class by the club (trainer change, time change) may affect the rolling booking
Alternative Paths
  • Book each class occurrence individually instead of as a rolling booking
  • Book a structured Course if a fixed multi-session format is preferred
  • Contact reception to set up a recurring booking manually

  • Home dashboard featured content cards
  • Push notification for new content releases
  • Recommendation after completing an in-studio or live class

  • Available 24/7 regardless of club opening hours
  • Included in standard membership — premium content may require an upgrade
  • Live stream content requires joining at the scheduled broadcast time
  • Recorded versions of live sessions may be made available after broadcast
  • Content catalogue may change — some videos are removed or rotated periodically
Alternative Paths
  • Attend the same class in person at the club if a live session is preferred
  • Access content via the club website or desktop browser if available
  • Book a live class through the standard booking flow for a scheduled session
